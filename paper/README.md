# Paper draft

`zzn.tex` (LaTeX, with `references.bib` and the figures in `figures/`, generated from
`docs/figures/make_figures.py` and converted to PDF with Inkscape).

Build with `make` (output `build/zzn.pdf`). Needs TeX Live with `texlive-latex-extra` and
`texlive-science` (for `algorithm` and `algpseudocode`).

The bibliography entries should be checked against the published versions; the author list is a
placeholder.
